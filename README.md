# 🚧 RoadGuard — Smart Road Hazard Reporter

RoadGuard is a beginner-friendly Python project for recording, tracking, and managing road hazards such as potholes and damaged roads.

## Features

- Submit road hazard reports
- Save reports locally in JSON format
- Assign unique report IDs
- View all saved reports
- Search by report ID, location, or hazard description
- Mark reports as resolved
- Validate user input

## Technologies Used

- Python
- JSON for local data storage

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python roadguard.py
   ```

## Data Storage

Reports are stored in `reports.json`, which is created automatically when the first report is submitted.

## Future Improvements

## Disclaimer

RoadGuard is currently a local prototype. It does not automatically verify road conditions or send reports to government authorities.
